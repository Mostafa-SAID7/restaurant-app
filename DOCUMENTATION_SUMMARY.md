## 🔄 Documentation Maintenance

### When to Update Documentation

1. **After Adding Features**
   - Update CHANGELOG.md
   - Update relevant docs/ files
   - Update README.md if major feature

2. **After Changing Architecture**
   - Update docs/ARCHITECTURE.md
   - Update docs/CONTRIBUTING.md if patterns change
   - Update CHANGELOG.md

3. **After Updating Dependencies**
   - Update docs/SETUP.md
   - Update README.md tech stack
   - Update CHANGELOG.md

4. **After Deployment Changes**
   - Update docs/DEPLOYMENT.md
   - Update docs/DOCKER.md if applicable
   - Update CHANGELOG.md
