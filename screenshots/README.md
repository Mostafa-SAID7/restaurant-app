## Adding Screenshots

When adding new screenshots:

1. Use descriptive filenames
2. Organize by feature/page
3. Include both desktop and mobile views
4. Use consistent dimensions
5. Update this README with descriptions

## Screenshot Guidelines

- **Resolution**: 1920x1080 for desktop, 375x667 for mobile
- **Format**: PNG or WebP
- **Quality**: High quality, no compression artifacts
- **Content**: Show real data, not placeholder text
- **Consistency**: Use the same theme/styling across screenshots

## Tools

Recommended tools for taking screenshots:

- **Windows**: Snipping Tool, ShareX
- **macOS**: Screenshot tool, Cleanshot X
- **Linux**: GNOME Screenshot, Flameshot
- **Browser**: Built-in DevTools, Playwright
